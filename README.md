# Telegram Web client — переработанная версия

Браузерный клиент на GramJS с адаптивным интерфейсом: список чатов слева на компьютере и отдельный экран переписки на телефоне.

## Что реализовано

- Переработанный интерфейс чатов и переписки, адаптация под iPhone и компьютер.
- Поиск по загруженным диалогам.
- Имена авторов сообщений, в том числе в группах (если Telegram API возвращает данные отправителя).
- История загружается порциями при прокрутке вверх; есть отдельная кнопка загрузки предыдущей порции и кнопка загрузки всей доступной истории.
- Сохранение позиции прокрутки при подгрузке старых сообщений.
- Календарь для перехода к сообщениям выбранного дня.
- Ответы на сообщения и переход к исходному сообщению.
- Отображение реакций, отправка/снятие стандартной эмодзи-реакции и просмотр списка участников, если Telegram разрешает его получить.
- Отправка фото и видео, просмотр и локальное сохранение полученных медиа.
- Локальное хранение загруженных сообщений, редакций, реакций и медиа в IndexedDB.
- Пометка сообщения как удалённого, если клиент успел получить его раньше и затем получил событие удаления от Telegram.
- Исправленная сборка через `npm run build` и автоматическая публикация на GitHub Pages.

## Локальная сборка

Требуется Node.js 20 или новее.

```bash
npm install
npm run build
```

Собранный сайт появится в папке `dist/`.

## Публикация на GitHub Pages

1. Загрузите **содержимое этой папки** в корень репозитория GitHub (не сам ZIP-файл).
2. В репозитории откройте **Settings → Pages**.
3. В поле **Build and deployment → Source** выберите **GitHub Actions**.
4. Откройте вкладку **Actions** и дождитесь успешного workflow **Build and deploy Telegram client**.
5. Адрес сайта появится в **Settings → Pages**.

Workflow находится по точному пути `.github/workflows/pages.yml` и запускается после каждого push в ветку `main`, а также вручную из вкладки Actions.

## Ограничения Telegram API и браузера

- Нельзя восстановить содержимое сообщения, удалённого до подключения клиента. Клиент сохраняет сообщение заранее и помечает его удалённым только если успел получить исходное сообщение и затем событие удаления.
- При открытии чата загружается последняя порция сообщений; более старые сообщения подтягиваются при прокрутке вверх. Кнопка «Загрузить всю историю» может работать долго в больших переписках и расходовать трафик.
- Список пользователей, поставивших реакцию, доступен не во всех типах чатов и не для всех сообщений.
- Временные фото/видео можно сохранить только если клиент получил доступ к медиа до его исчезновения и успел загрузить его в IndexedDB. Это не гарантируется для уже истёкших вложений.
- Вкладка браузера не работает как постоянно запущенный Telegram-клиент после закрытия или выгрузки системой. Удаления, произошедшие в это время, могут быть не замечены.
- Это не официальный клиент Telegram; часть возможностей и поведение могут отличаться от официальных приложений.

## Безопасность

API-ключи и строка авторизации Telegram сохраняются в `localStorage` браузера. Не публикуйте их, не отправляйте другим людям и не используйте клиент на чужом устройстве. Для выхода используйте меню приложения.
